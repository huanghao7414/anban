# 体检报告原文整理

先核对项目、数值、单位、报告自己的参考范围及标记。只提取可见文字，不补造参考范围；文字不清时留空并询问。

程序接入时使用下面的结构；`flag` 只能为 `high`、`low`、`normal`、`unknown`。没有明确标记时用 `unknown`，不要自行把一项结果判定为正常或异常。

```json
{
  "indicators": [
    {"name": "", "value": "", "unit": "", "reference": "", "flag": "unknown"}
  ],
  "unreadable": true
}
```

面向长辈时，使用“报告上写了什么 → 这个标记表达什么 → 哪些信息需要核对”的顺序。向上或向下标记可解释为高于或低于这张报告给出的参考范围；不能由单项异常得出疾病结论。

本包不包含临床诊断知识库。超出报告原文的指标含义或生活建议，需要宿主提供可追溯资料并核对适用条件；没有资料时停止在原文整理，不编造个体饮食、补剂或治疗方案。

输出卡片时保留“不替代执业医师诊断与处方调整”，使用正常可读字号。用药卡脚本不接受报告数据；报告应使用宿主实际可用的排版工具。
