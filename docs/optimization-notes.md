# 安伴功能优化说明

这次更新恢复了提交材料中的 DeepSeek Harness Web 插件、体检报告解读知识库和千问语音，并调整了从上传、核对到查看结果的流程。

- **药盒与用药卡**：补拍照片归入原药盒，显示处理进度和缩略图。核对时可选择每天 1、2 或 3 次，分别填写时间、用量与餐前餐后关系。包装或医嘱原文中的明确用量作为待核对候选。生成用药卡时可设起止日期，首页七天药盒只显示周期内的安排。大字卡和导出图片突出时间与每次用量。
- **PDF 与体检报告**：先勾选页面，再主动开始识别。处理中显示当前页、已处理页数和等待时间，已返回的指标可先核对。补选时复用已成功识别的页面，失败页可单独重试。报告大字卡把结果、参考范围和通俗解读分开。知识库未收录的项目会尝试匹配公开医学资料，并附可核实的来源。
- **生活提示与记录**：首页依据用户确认的报告指标显示小结、待核对项目和有资料支持的生活提示。所选指标均在参考范围内时，提示只涵盖本次核对的项目。新生成的解读按次保存，实际服用由用户在用药卡手动登记，也可撤销当天的登记。
- **定时提醒**：同一条提醒只弹一次，过期提醒不补弹。保存提醒后按药品和该次用量提前合成语音并缓存，到点读取已生成的音频。音频未就绪时仍有文字和手动朗读；浏览器拦截自动播放时可点播放。
- **本地配置**：支持智谱对话和视觉模型，以及千问 TTS。配置和启动方法见 [项目 README](../README.md) 和 [Harness 插件安装说明](../exports/anban-harness-web/README.md)。

体检报告和服用记录按本地账户保存。仓库仅提供配置示例、测试与演示资料。
